# 参考剪辑规格

## 参考分工

本 Skill 使用两组参考，不把它们混成一种不明来源的平均风格：

- 陌言 01–03：负责情绪文案、旁白态度、情绪递进和结尾收口。
- “十二”04–06：负责片头交互、真实书封轮播、字体、明亮动态画面、顶部书籍信息和中英字幕。

参考文件见 [reference-media-index.md](reference-media-index.md)，“十二”逐帧实测见 [shier-template-frame-analysis.md](shier-template-frame-analysis.md)。

## 片头

只使用 [opening-interaction-spec.md](opening-interaction-spec.md) 定义的 `masked_book_carousel`。固定次序为：

```text
目标书主画面预闪 3 帧
→ 黑底情绪句与毛笔关键词
→ 同源视频横带向上下展开
→ 按书名真实时码动态计算数量的标准化真实书封卡硬切
→ 齿轮结束后目标书封清楚展示，书名在同一封面页上方由大到小收稳，水滴声触发书名与封面整页水面形变，保持该页到书名及停顿结束
→ 正文
```

不使用人像逐字片头、纯大字片头、纯书封轮播片头或书封滑动容器。

## 正文画面

### 构图语法

- 使用可读的中间调和自然光，主色允许绿、青、蓝、米白、柔金和低饱和暖棕。
- 阴影保留层次，人物、动物、道路或远景必须能在手机上被读出。
- 优先草地、海岸、道路、车窗、旷野、湖面、山地等开阔空间；只在文案必要时使用室内。
- 人物多为远景、背影、侧身或行走，不对镜头口播。不强制全片是同一个人，但风格、时代和服装不得漂移。
- 画面必须预留顶部书名区、中下部字幕区和底部账号标识安全区。
- 禁止恐怖、阴森、鬼影、无脸密集人群、巨大嘴部、裂脸、强压迫噩梦和 80% 纯黑画面。

### 镜头节奏

- 不按句号换画面，只在心理阶段、人物关系、空间、象征物功能或行动方向改变时换镜。
- 正文素材数量不固定。“十二”样例的动态正文常见为 3–5 组，每组 7–14 秒；更短成片可 2–4 组，更长成片按情绪阶段自然增加。
- 长镜头必须有画面内运动，不能把一张图静止 10 秒再冒充参考风格。
- 记忆碎片和强转折使用硬切；情绪连续段落才使用 0.12–0.30 秒短淡化。三个及以上正文转场不得全部同型。

### 动态优先级

1. 已授权实拍视频或自有视频。
2. 已通过逐帧质检的图生视频，只保留自然运动。
3. 静态图 + 可编辑确定性轻运动。

图生视频优先给目标书主画面和 1–3 个关键正文长镜头。它们可包含风动、人物远景行走、动物缓慢移动、车辆前进和轻微摄影机移动；禁止嘴型变化、增加人物、突然转身、镜头抖动和物体融化。

静态图使用确定性轻运动：`zoom_in` 为 1.00→1.10–1.13，`zoom_out` 为 1.10–1.13→1.00，`pan_left/right` 保持 1.08–1.13 放大且横移不超过画宽 4%，`emotional_hold` 为 1.00→1.025。前四种相邻交替，不连续重复。图片放入覆盖全画布且隐藏溢出的容器，只移动内部图片，逐帧不得露黑边。

## 旁白与混音

- 情绪钩子从 0.00s 开始。“今天分享的是”和书名是片头的两个独立节奏节点，不念作者。
- “今天分享的是”说完后停 0.45–0.65 秒，再单独念书名；书名低位、结实、下收。书名念完后再停 0.45–0.70 秒，正文才进入。书名约从 4.0s 开始念，正文从约 5.3–5.8s 开始，不在 4s 提前 J-cut。
- 声音全程连续，不因遮罩、书封卡或切镜重新起句。
- BGM 默认无歌词、无明显鼓点、无抢耳主旋律。旁白期间闪避 3–5dB，旁白主观领先 10–14dB；乐器底床应清楚可闻，建议约 -26至-23 LUFS，不能为了保人声把整条音乐压到接近消失。
- 整体响度目标 -10.5 至 -9.5 LUFS，LRA 2–4 LU，真峰值不超过 -1dBTP。

## 完成度细节

- 第 0 秒已有声音，前 3 帧闪过目标书主画面。
- 毛笔字里的视频和横向展开使用同一段素材，不跳时间码。
- 片头书封数量按书名首字真实时码反推，每张使用 3–4 帧 `snap_settle` 后硬切；目标封面与书名首字同帧进入。书名从封面页第 1 帧起就在封面上方安全区出现，用 10–14 帧由 135%–155% 收稳到 100%，过程中封面全程可见。水滴音触发“书名＋封面＋背景”当前整帧页面的低幅位移映射，0.30–0.50 秒内起伏并连续恢复；恢复后继续保持书名封面同页，直到书名末字及书名后停顿结束。正文第一句开始时才切第一正文镜头。禁止可见水珠、下落轨迹、落点飞溅、椭圆/同心圆轮廓和高光环。
- 顶部书名和作者从锁定到结尾稳定不动。
- 画面动态先来自素材内部，关键帧推拉只是回退手段。
- 最后一句说完后留 0.2–0.5 秒直接结束，不设片尾。
