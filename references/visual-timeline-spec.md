## 画面职责

一组画面负责一个完整心理阶段，不负责逐句图解。旁白负责判断和情绪，字幕负责当前意群，画面负责让该阶段被感受到。

- 每组画面必须绑定一段或多段连续逐字稿 ID、原文和实测配音起止点；先理解口播中的人物处境、情绪动作和空间隐喻，再决定场景。
- 优先呈现人物行为、空间关系和运动方向，少用抽象符号堆叠。
- 正文统一使用人物清晰侧脸与风景的组合：人物为中远景或远景，脸朝画面内侧，风景占主要面积。禁止纯风景、纯背影和正脸近景。
- 画面保留顶部书名区、中下部字幕区和底部签名区。
- 不将字幕与画面一一绑定；一组长镜头可承载 2–5 张字幕卡。

## 自适应镜头数量

数量从心理阶段推导，不从“30 秒应该几张图”反推。

1. 为每段口播标记主体、人物关系、心理状态、叙事空间、运动方向、象征物功能和因果阶段。
2. 相邻段的上述字段没有实质改变时合并，即使中间有句号也不换镜。
3. 第一组使用 `visual_change_reason: initial_state`。
4. 后续只有命中下列一项才新增画面：
   - `subject_relation_change`
   - `psychological_state_change`
   - `narrative_space_change`
   - `symbol_change`
   - `causal_stage_change`
   - `action_release`
5. 完成语义划分后再查密度：动态镜头常见 7–14 秒/组，回退静态图常见 5–9 秒/组。短于 4 秒要检查是否过密，长于 15 秒要检查是否有未拆出的心理转折。

观察值仅用于质检：约 28–53 秒的“十二”样例自然形成约 3–5 组动态正文镜头。更短或更长的新成片不得硬套该数字。

## 明亮电影感语法

默认母视觉：

```text
3:4 竖幅，当代东方电影感，开阔自然空间，
空气清透、能见度高、细节清晰，方向明确但不过曝的自然光，正常黑白层次与适度对比，
青绿清晰有层次，暖色适量，颜色干净但不过度艳丽，不灰、不脏、不泛白，
人物为中远景或远景的清晰侧脸，面向画面内侧，安静停留或极慢行走，
女孩穿轻薄针织衫、衬衫、短外套、轻便上衣或简洁连衣裙，不穿长大衣或过膝风衣，
侧脸神情、身体状态和视线方向必须与当前口播的情绪动作一致，
风景占画面主要面积，并由口播语义选择草地、山坡、海岸、湖面、树林、旷野、站台或远路，
环境的空间距离、天气、光线和运动线索承担当前口播的情绪功能，
有风、草、水面、动物或车辆中的一种自然运动线索，
顶部留出书名作者安全区，中下部留出字幕安全区，
无文字，无书名，无 Logo，无水印；无雾、无霾、无白纱感、无奶油滤镜、无灰白蒙层、无低对比泛白、无过曝高光、无大面积柔焦。
```

质检基准：

- 主体、地平线和行动方向在 25% 手机缩略图上仍然可读。
- 每张图必须能回答“它对应哪段口播”；删除字幕后仍能感到相同的处境或情绪动作。通用治愈风景图直接打回。
- 人物必须存在且为侧脸，`face_orientation: side_profile`；只允许 `shot_size: medium_long` 或 `long`，风景必须是构图主体之一。
- 女孩服装必须轻便且符合场景，`long_coat: false`；长大衣、过膝风衣、厚重拖地外套直接打回。
- 画面必须标记 `character_emotion`、`environment_emotional_function` 和 `emotion_environment_alignment_reason`。三项均从 `narration_text` 推导，不能只写“忧郁”“治愈”“氛围感”等空泛词。
- 成像必须是 `clarity: clear_transparent`、`atmospheric_haze: none`、`white_veil: false`、`contrast: clean_mid_contrast`。出现雾蒙蒙、白蒙蒙、奶油滤镜、灰白罩层、黑位抬起或高光过曝直接打回。
- 明度以主体和环境清晰可读为准，保留正常黑位与高光细节；禁止用整体抬白、降低对比或加雾制造“高级感”。
- 黑色或近黑区不得长期占画面 70% 以上。
- 整条视频有一致的绿/青/低饱和调色，但不强制每帧都是绿色。
- 不因为书的主题严肃就生成恐怖画面。严肃感来自空间、距离和行为，不来自裂脸、鬼影、密集嘴巴或无脸人群。

## 动态素材与确定性轻运动

“动起来”指画面内有可感知但克制的运动，不是图片弹跳和强转场。

### 默认全部轻动态化

- 当前锁定的图生视频提供方必须把每张成片 `shot-NN.png` 以自身作为 `source_image` 生成对应轻动态素材，不设 3 张上限。默认是 Grok；只有本机 LTX-2.3 探针和单镜头验收通过时才可显式改为 `ltx_local`。
- 每条最终动态素材的时长由该图绑定的配音区间决定：`target_duration_seconds = voice_end - voice_start`。Grok 的 6/10 秒只是原始生成档位，不能作为最终上轴时长。
- 真实书封、书封轮播卡、毛笔字遮罩、字幕图和任何含文字素材不送入图生视频模型。
- 每个镜头只允许一种低幅动作，优先风动、草叶、水面、窗光、衣角或远处剪影；默认相机完全固定。
- 人物默认保持姿势、面部、身体和画面位置不变。只有源图已明确表现远景行走，才允许极慢延续一步；不得转身、走近镜头或做明显肢体动作。
- 禁止对话嘴型、表情变化、人脸或手部重绘、新增人物、物体溶解、明显推拉、摇移、环绕、景深拉焦、二次切镜和画风漂移。
- 每个动态镜头逐帧复核；不合格就回退，不使用局部打码或快切隐藏问题。

### 静态图片的确定性轻运动

```text
zoom_in：scale 1.00 → 1.10–1.13
zoom_out：scale 1.10–1.13 → 1.00，默认从 1.12 开始
pan_left：scale 保持 1.08–1.13，pan_x_ratio 为 -0.01 至 -0.04
pan_right：scale 保持 1.08–1.13，pan_x_ratio 为 0.01 至 0.04
emotional_hold：scale 1.00 → 1.025
```

这五种运动用于直接上轴的静态图片和具名回退图片。主体仍是静态画面，不做人脸、嘴型、手脚或骨骼动画。`zoom_in`、`zoom_out`、`pan_left`、`pan_right` 按镜头交替，相邻静态镜头禁止重复同一种运动；`emotional_hold` 只用于情绪停顿、记忆定格或末句，不得连续出现。

每个静态场景必须记录：

```json
{
  "motion": {
    "type": "zoom_in",
    "scale_start": 1.0,
    "scale_end": 1.12,
    "pan_x_ratio": 0.0,
    "pan_y_ratio": 0.0,
    "interpolation": "cubic_ease_in_out",
    "sample_per_frame": true,
    "container": {
      "coverage": "full_canvas",
      "overflow": "hidden",
      "fit": "cover",
      "transform_target": "inner_image"
    }
  }
}
```

容器覆盖完整画布并隐藏溢出，只有内部图片接受缩放和平移。禁止移动整个场景层。`pan_left` 和 `pan_right` 必须先放大再横移，横移绝对值不得超过画面宽度 4%；任何一帧出现黑边即失败。插值使用逐帧 `cubic_ease_in_out`，整段只完成一次运动，不循环、不弹跳。

已验收的模型轻动态素材使用 `motion.type: grok_video` 或 `motion.type: ltx_video`，默认不再叠加上述缩放或平移，避免模型运动与镜头运动相互放大。

## 语义选镜

| 文案功能 | 画面状态 | 运动线索 |
|---|---|---|
| 替观众表达 | 一个人停在开阔空间中 | 只让风、衣角或草地之一轻动 |
| 压力递进 | 人与人群、道路或巨大空间形成距离 | 只让远处人群或车辆沿原方向缓慢移动 |
| 认知反转 | 视角拉远，人物开始观察 | 固定镜头，只让水面反光或云影缓慢变化 |
| 行动许可 | 人物沿路、坡地或出口准备移动 | 远景衣角、草或车辆之一轻动，人物不走近镜头 |
| 身份收口 | 更开阔、更有光的远景 | 柔光或风轻变，人物位置保持稳定 |

人物和环境不是装饰。`替观众表达` 可用收紧下颌、回避视线和停步；`压力递进` 可用肩背略紧、侧脸警觉和更强空间距离；`认知反转` 改为凝视远方、神情集中，并让道路或水面出现清晰方向；`行动许可` 放松肩颈、视线朝出口或前路；`身份收口` 使用平静坚定的侧脸和更开阔、清亮的环境。所有变化必须以当前文案为依据，不机械套用。

## 四轨时间轴

```text
sceneTrack       主画面、动态素材或回退微动
captionTrack     中英字幕内容和时间
accentTrack      必要的局部柔光或视觉强调
transitionTrack  新旧场景叠化区间
```

`accentTrack` 不负责伪造人物动作。已在素材内的光、草、动物和车辆不拆层。

## 配音锁时规则

- 唯一总时长来源为 `manifest.duration.locked`，并在时间轴写入 `duration_source: manifest.duration.locked` 与 `voice_timing_source: 05-配音/timing-vNNN.json`。
- 第一组正文的 `voice_start` 等于 `opening.body_voice_start`，最后一组正文的 `voice_end` 等于锁定总时长；相邻 `voice_end` 与下一组 `voice_start` 误差不超过 0.05 秒。
- `sceneTrack.start <= voice_start < voice_end <= sceneTrack.end`。画面叠化允许相邻场景重叠 0.3–0.5 秒，但配音责任区间不重叠、不留缝。
- 每个场景必须保存 `script_segment_ids`、`narration_text`、`voice_start`、`voice_end`，并与 `image-generation-vNNN.json.shots` 中同一 `source_still` 完全一致。
- 配音轨从 0 开始并在锁定总时长结束；时间轴、BGM、最终视频也在同一终点结束，不额外补黑场。

## 字幕状态

每张字幕至少包含：

```json
{
  "id": "cap-03",
  "start": 12.4,
  "reveal_end": 12.4,
  "end": 15.1,
  "zh": "中文意群",
  "en": "Short English meaning",
  "scene_id": "scene-02"
}
```

- 中文默认 5–14 字，最多 16 字；默认一行。
- 字幕在意群起点整段直接显示并保持，禁止逐字、打字机、按词弹出或渐进补全。
- `captionTrack` 从片头配音意群开始。至少完整覆盖 `opening.hook_start` 到 `opening.expand_end`，使两字遮罩与横带展开期间始终有对应的底部配音字幕；顶部情绪句不算字幕。

## 静态图片运动验收

- 每张静态图片必须完整执行一次具名运动，不得静止或循环。
- `zoom_in`、`zoom_out`、`pan_left`、`pan_right` 相邻不得重复；运动方向服从人物视线、道路和构图重心。
- 渲染器必须逐帧计算插值，禁止离散跳值。
- 逐帧检查全画布覆盖与 `overflow: hidden`，任意帧露出黑边直接失败。
- Grok 真动态素材不再叠加确定性缩放或平移。
- 英文是意译，尽量一行，不与中文抢层级。

## 转场

- 遮罩和轮播只使用片头规格定义的展开与硬切。
- 目标书锁定是硬切，结束轮播速度感。
- 记忆碎片和强转折使用 `hard_cut`，并记录 `reason: memory_fragment` 或 `reason: strong_turn`。
- 情绪连续的正文段落才使用 `short_fade`，时长 0.12–0.30 秒，并记录 `reason: emotional_continuity`。
- 新镜头在新语义开始前 0.1–0.2 秒进入；硬切发生在语义切点。
- 三个及以上正文转场不得全部使用同一种类型。
- 不使用闪白、旋转、缩放弹跳、格子分屏和强节拍转场。

## 验收

1. 先不看字幕，检查每个换镜是否对应真实心理阶段变化。
2. 检查所有正文画面是否清透、有正常对比和高光细节，是否完全没有雾蒙、白蒙、奶油滤镜和灰白罩层。
3. 逐帧检查动态镜头的脸、手、人数、动物四肢和背景连续性。
4. 检查每张成片正文图是否都有对应的 Grok/LTX 动态片段或具名回退记录；在 25% 手机预览中运动应可感知但不抢字幕，回退图不得冒充真动态。
5. 检查每张图的侧脸神情、身体状态、女孩服装、环境和逐字稿绑定；禁止长大衣、通用忧郁表情、通用治愈风景、纯背影、纯风景或正脸近景。
6. 检查所有最终动态片段、场景口播区间、配音轨、时间轴和最终 MP4 是否共同服从锁定时长。
7. 在 25% 缩略图和手机外放条件下查看，书名、中文字幕和主体必须同时可读。
8. 结尾在配音文件自带的 0.2–0.5 秒尾音结束处停止，没有额外空黑片尾。
